# 截图自查清单

对着桌面和手机截图逐条检查。每条都要有明确结论：通过 / 已修 / 刻意保留（写原因）。

## 文字

- [ ] 没有写给开发者或验收方看的说明、口径、操作提示
- [ ] 没有复述标题的副标题
- [ ] 没有内部 ID、需求编号、代号（需要用户复制的标识除外）
- [ ] 同一信息只出现一次
- [ ] 没有数据的模块已隐藏，或只有一句空状态
- [ ] 图表上没有逐点数值标注
- [ ] 不可逆操作有一句话的后果提示

## 视觉

- [ ] 颜色只有主色、4 个语义色和灰阶；标签颜色不超过 5 种
- [ ] 没有渐变文字、发光、彩色阴影、emoji 图标
- [ ] 阴影只出现在浮层上；没有卡片套卡片
- [ ] 圆角全站一致
- [ ] 字号不超过 4 级；数字等宽、单位小一号灰色
- [ ] 每个区域只有一个主按钮
- [ ] 间距一致，同一行元素对齐，没有挤在一起或大块空洞

## 布局与状态

- [ ] 手机宽度下没有横向滚动条，文字没有截断成"…"导致看不懂（价格、名称尤其注意）
- [ ] 宽屏下内容没有拉得过宽或出现空白条（横向滚动区域滚到尽头也看一下）
- [ ] 页签、弹窗、空状态、加载态、错误态都截图看过
- [ ] 文字和标签没有互相重叠（地图标注、图例、长标题）
- [ ] 控制台没有新增报错

## 整体感受（最后看一眼）

- [ ] 把截图缩小到一半看：视线第一眼落在最重要的数据或操作上吗？
- [ ] 像一个成熟产品，还是像带批注的草稿？
