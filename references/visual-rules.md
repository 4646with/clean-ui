# 视觉规则

原则：**少即是统一。** 每多一种颜色、字号、圆角、阴影，界面就更像拼凑的。项目已有 token 时以项目为准，下面的数值是没有体系时的默认值。

## 颜色

- **一个主色**（按钮、链接、选中态、关键数据）。
- **四个语义色**：成功绿、警告橙、危险红、信息（与主色同色）。只表达状态，不做装饰。
- **灰阶**负责其余一切：正文、次要文字、边框、分隔线、背景层次。
- 组件库自带的 cyan / purple / magenta / geekblue / lime / volcano 等装饰色，统一收回主色或灰色。标签颜色最多 5 种：主色、红、橙、绿、灰。
- 饱和度要低：语义色用于文字和细边框，背景只用它的浅色版（如红 `#d9434a` 配背景 `#fdf0f0`）。
- 不用渐变文字、霓虹发光、彩色阴影。深色"大屏"风格只用在确实需要的单个模块，不铺满整个后台。

## 层次：靠背景和细线，不靠阴影

- 页面背景浅灰（如 `#f0f2f5`），内容区白色，这就分出了两层。
- 分区用 1px 浅色分隔线（如 `#ebeef5`），不用阴影。
- 阴影只给浮层（下拉、弹窗、气泡），而且要淡（`0 2px 8px rgba(0,0,0,.08)`）。
- **不要卡片套卡片**。一个分区内部再分块，用分隔线或留白。

## 圆角

- 全站统一 1～2 档：后台类 2～4px；产品官网、营销页 6～12px。
- 同一个元素内，内层圆角 ≤ 外层圆角。
- 不要一部分 2px、一部分 16px 混用。

## 字号与字重

- 最多 4 级：辅助 12、正文 13～14、标题 15～16、关键数字 22～28（营销页大标题另算）。
- 字重只用两档：400 正文、600 标题和数字。不用 300 细体做正文，不用 800 粗体做标题。
- 数字一律等宽数字：`font-variant-numeric: tabular-nums`。表格、KPI、价格的数字列右对齐。
- 单位比数字小一号、用次要灰色：`<b>42</b><small>ms</small>`。
- 次要文字用灰色区分，不用缩小字号区分；12px 已经是下限。

## 间距与对齐

- 间距取 4 的倍数：4 / 8 / 12 / 16 / 24 / 32。页面内边距、卡片内边距全站统一。
- 同一行的元素顶部或基线对齐；标签、按钮、输入框高度一致。
- 宁可多留白，也不要用边框和底色把每个元素框起来。

## 常见组件

- **KPI**：同一行的指标合成一条统计栏（白底、竖线分隔），不要做成一排各自带阴影和图标的小卡片。每个指标只放：名称、数字 + 单位、可选的一行环比。
- **表格**：表头浅灰底、无竖线；行高适中；操作列只放 1～2 个文字按钮，其余收进"更多"。状态用小标签，不用整行变色。
- **标签 Tag**：无边框或浅边框、小圆角；同一张表里的标签颜色只代表一种含义（如风险等级）。
- **按钮**：每个区域只有一个主按钮，其余用默认或文字按钮。去掉按钮阴影和点击波纹。
- **图标**：用同一套线性图标库，大小统一（14～16px）。不用 emoji。不必每个菜单项、每个标题都配图标。
- **空状态 / 加载**：骨架屏或居中一句话，不放大插画（除非产品本身有插画体系）。
- **动效**：150～200ms，只用于状态切换和浮层出现；不做入场弹跳、不做循环动画（实时状态指示点除外）。

## 图表

- 一套共用调色板，第一色是主色，后面是主色的浅色和灰色，红橙只给"风险 / 异常"类数据。
- 去掉多余的网格线、坐标轴线；保留必要刻度。
- 数值靠 tooltip 和图例展示，不在每个点上标数字。
- 一张图只回答一个问题；不确定用什么图时，用条形图。
- 多张图的数字要和页面上的 KPI 对得上（合计、比例前后一致）。

Ant Design 写法示意：

```tsx
<ConfigProvider wave={{ disabled: true }} theme={{
  token: { colorPrimary: '#2559e6', colorSuccess: '#2f9e6b', colorWarning: '#e0942c', colorError: '#d9434a',
           borderRadius: 4, borderRadiusSM: 2, fontSize: 13, colorBgLayout: '#f0f2f5', colorTextBase: '#262b36',

    Table: { headerBg: '#f5f7fa', headerSplitColor: 'transparent', rowHoverBg: '#f5f8ff' },
    Button: { primaryShadow: 'none', defaultShadow: 'none', dangerShadow: 'none' },
  },
}}>
```

Tailwind / shadcn：把上面的值写进 CSS 变量（`--primary`、`--border`、`--radius` 等），组件里只用变量，不写 `text-purple-500` 这类直接色值。
