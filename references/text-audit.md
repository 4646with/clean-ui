# 文字审计：哪些字该删，删了用什么替代

核心问题：**用户如果不看这行字，会做错什么吗？** 不会就删。

## 一、几乎总该删的

| 类型 | 典型例子 | 替代做法 |
| --- | --- | --- |
| 写给开发者 / 验收方看的说明 | "这条链路是真实调用""评估口径：留一法……""风险分按以下规则累加" | 挪到 README 或文档；界面最多留一个 `?` 图标，悬停查看 |
| 操作提示 | "点击行可查看详情""拖拽节点进行编排""保存后立即生效" | 用交互本身表达：行悬停变色 + 手型光标、可拖元素带拖拽手柄；保存后弹 toast "已保存并生效" |
| 复述标题的副标题 | 标题"通话记录"，副标题"查看和管理所有通话记录" | 删掉副标题。只有副标题提供了标题没有的信息才保留 |
| 需求编号、条款原文、内部代号 | "对应需求 3.2.1""RG-0042 规则组""voice_id: zh_female_xx" | 界面用通用产品名；对照关系写进文档。需要用户复制的标识（API 调用名、订单号）例外 |
| 自我标注 | 每张卡都写"演示数据""示例""Beta" | 全页最多一处；能不标就不标 |
| 署名、背书、营销话术堆叠 | 每屏都放合作伙伴 logo、"行业领先""极致体验" | 背书只放在首页一处；功能页只放功能 |
| 重复信息 | 同一个价格在卡片头和表格里各出现一次；分组倍率全是 1 还列一张倍率表 | 只显示一次；全是默认值的表整块不显示 |
| 空数据的模块 | "性能数据：暂无""--"占满一整块 | 没有数据时整块隐藏；确实需要让用户知道"还没有"时，用一句空状态 |
| 图表上的冗余标注 | 每个点都标数值、每根柱子顶上都有数字、额外的"图表说明" | 悬停 tooltip 显示数值；图例带总数和占比即可 |
| 装饰性数字 | 登录页上的"已服务 10,000+ 企业""99.99% 可用" | 登录页只做登录；指标放进汇报材料或首页 |

## 二、应该保留，但要压短

- **后果提示**：删除、覆盖、扣费、发送等不可逆操作 → 放在确认框里，一句话说清后果（"删除后 3 条关联任务也会停止"）。
- **错误信息**：说清楚哪里错了、怎么改，不写"操作失败，请重试"这种无信息的话。
- **单位与口径**：单位必须有（小一号、灰色跟在数字后）；口径会影响判断时，用 `?` 悬停说明，不铺在页面上。
- **空状态**：一句话 + 一个主操作按钮（"还没有任务，[新建任务]"）。
- **表单字段说明**：只在格式不明显时写（"多个号码用换行分隔"），放在输入框下方，一行。

## 三、措辞

- 用户的语言，不用内部语言：写"订单管理"，不写"3.4 订单处理子系统"；写"音色：温柔女声"，不写音色 ID。
- 按钮写动作结果："导出 CSV""发布"，不写"点击此处进行导出操作"。
- 数字比形容词有用："P95 42ms"，不写"响应极快"。
- 不用感叹号，不用 emoji 当图标或强调。

## 四、自查方法

写完一屏后，把页面上所有非数据文字列出来，逐条标"删 / 挪到文档 / 换成交互 / 保留"。保留的那几条才是界面该有的字。
